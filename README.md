# talk-glass（ベータ版）

会議の会話（相手と自分）を流れるログとして画面に出し、気になる部分をドラッグすると、その部分についてだけ AI が解説と返し方を答える Windows アプリです。

- **この exe の中に生成 AI は入っていません。** 回答は、利用者の PC に別途インストール済みの Codex（OpenAI）を、利用者自身の ChatGPT アカウントで呼んで生成します
- 音声認識（Whisper）は PC の中で完結します。音声そのものが外部に送られることはありません
- 外部に送られるのは、AI に聞いたときの「選んだ会話の文字」と、「画面を見て聞く」を使ったときの前面の窓の画像だけです
- HUD は既定では画面共有や録画に映りません（設定で映すこともできます）

## 必要なもの

- Windows 11（64bit）・メモリ 8GB 以上
- Codex デスクトップアプリ（OpenAI）が入っていて、ChatGPT の Plus 以上のプランでログイン済みであること。API キーは使えません（追加課金は発生しません）
- 初回起動時に音声認識モデル（約 0.5GB）を自動ダウンロードします。通信が発生するのは、このときと AI に聞くときだけです

## ダウンロード

[Releases](../../releases) から最新の `talk-glass-x.x.x.zip` をダウンロードしてください。

## インストール

1. zip を任意のフォルダに展開する（例: `C:\Tools\talk-glass`。日本語や空白を含まないパスが無難です）
2. `talk-glass.exe` を実行する
3. 「Windows によって PC が保護されました」と出た場合は「詳細情報」→「実行」を選ぶ（署名なしアプリのための標準的な警告です）
4. タスクトレイにアイコンが出て、会話の取り込みが始まります

## 使い方

| 操作 | 既定のキー |
|---|---|
| 選択モード（ログをドラッグして聞く。Shift を押しながらだと最初からじっくり） | Ctrl+Alt+S |
| 直近の会話の流れ（10行・相手と自分）について聞く | Ctrl+Alt+A |
| いま見ている画面を見て、直近の流れについて聞く | Ctrl+Alt+W |
| じっくり考える（直前の質問のやり直し、または直近20行を深く） | Ctrl+Alt+D |
| HUD の表示と非表示 | Ctrl+Alt+H |
| 会話の取り込みの開始と停止 | Ctrl+Alt+K |

回答は「読み替え」「解説」「標準」「ユーモア」「質問」に分かれて色分けされます。キーやモデル、HUD の行数などはトレイの「メインウィンドウ（設定）」で変えられます。詳細は同梱の `README.md` を参照してください。
